## ✨ Overview

**Pet Age Calculator** is a simple and interactive web app that allows the user to calculate their pet’s age in human years.  
Just enter your pet’s age, select Cat or Dog from the dropdown — and the page instantly shows you the human-equivalent age in a fun, _paw_-some user interface.

## ✅ Features

- Input your pet’s age in years 
- Use the dropdown to choose between Cat or Dog
- The page will instantly show you your pet’s age in human years
- Live demo hosted on GitHub Pages
